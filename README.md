# SmartCare-GD32-K230  
## 基于 GD32F4 与 K230 的智能辅助护理系统

本项目是一套面向卧床病人、行动不便人群和康复护理场景的智能辅助护理系统。系统以 GD32F4 系列单片机作为主控核心，结合 K230 AI 视觉模块、MLX90614 红外测温传感器、SHT30 温湿度传感器、ESP01S Wi-Fi 通信模块、舵机机械臂、OneNet 云平台和微信小程序，实现病人需求识别、体温检测、环境监测、机械臂护理辅助和远程监护提醒等功能。

---

## 1. 项目功能

- 基于 K230 摄像头识别病人眼睛注视方向；
- 通过 USART 将眼动识别结果发送至 GD32F4 主控；
- GD32F4 根据识别结果解析病人需求并执行对应指令；
- 通过 MLX90614 进行非接触式红外体温检测；
- 通过 SHT30 进行环境温湿度检测；
- 通过 PWM 控制多自由度舵机机械臂完成喂水等辅助护理动作；
- 通过 ESP01S 将病人需求和传感器数据上传至 OneNet 云平台；
- 通过微信小程序实现监护人远程查看与响应。

---

## 2. 系统架构

系统主要由以下模块组成：

1. K230 AI 视觉识别模块；
2. GD32F4 主控模块；
3. MLX90614 红外体温检测模块；
4. SHT30 环境温湿度检测模块；
5. 舵机机械臂执行模块；
6. ESP01S 无线通信模块；
7. OneNet 云平台；
8. 微信小程序监护端；
9. XL4015 降压稳压电源模块。

```text
病人眼部图像
    ↓
K230 AI 视觉识别

GD32F4 主控

    ├── IIC → SHT30 温湿度检测
    ├── PWM → 舵机机械臂
    └── USART → ESP01S → OneNet 云平台 → 微信小程序
